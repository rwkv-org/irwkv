# Security Policy

## Reporting security issues

Report vulnerabilities affecting irwkv privately to the repository maintainers.
Follow the [vulnerability reporting guidance](docs/contributing/vulnerability_management.md)
for private reporting and coordinated disclosure.

## Threat model

See the [irwkv Security Guide](docs/usage/security.md) for deployment assumptions
and recommendations.

See [PyTorch's Security Policy](https://github.com/pytorch/pytorch/blob/main/SECURITY.md)
for recommendations on handling models and distributed communication.

## Upstream policy

irwkv is derived from vLLM. For vulnerabilities affecting upstream vLLM,
follow the [vLLM security policy](https://github.com/vllm-project/vllm/security/policy).
